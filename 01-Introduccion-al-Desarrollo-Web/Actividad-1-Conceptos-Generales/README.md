## 📌 Objetivo de la Actividad

---

## 📖 Resumen de Conceptos Clave

### 1. ¿Cómo funciona Internet?
* **Dirección IP:** Número identificador único de cada máquina conectada a la red (como el número de teléfono o dirección de tu casa).
* **DNS (Domain Name System):** Libreta de direcciones que convierte nombres como `google.com` en su respectiva dirección IP numérica.
* **HTTP / HTTPS:** El protocolo (idioma) que usan navegadores y servidores para transferir páginas. La versión **HTTPS** viaja encriptada para mayor seguridad.

### 2. Modelo Cliente - Servidor
* **Cliente:** Quien solicita la información (tu navegador Chrome, Edge, etc.).
* **Servidor:** La computadora remota que procesa y responde con los archivos necesarios.
* *Analogía:* En un restaurante, tú eres el cliente que hace un pedido; la cocina es el servidor que prepara el platillo y el mesero es la red que lo lleva a tu mesa.

### 3. Front-End vs. Back-End
* **Front-End:** Todo lo visible con lo que interactúa el usuario (HTML, CSS, JavaScript, Angular).
* **Back-End:** La lógica de fondo, bases de datos (SQL Server, MySQL) y seguridad del servidor.

### 4. Páginas Estáticas vs. Aplicaciones Web (SPA)
* Las páginas estáticas recargan todo el sitio ante cualquier clic.
* Las SPAs (*Single Page Applications* como las hechas en Angular) cargan una sola vez y actualizan solo la parte necesaria, ofreciendo una experiencia rápida como una app de escritorio.
