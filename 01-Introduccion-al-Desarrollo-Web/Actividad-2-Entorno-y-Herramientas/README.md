# Actividad 2: Entornos de Desarrollo Web y Configuración

**Materia:** Aplicaciones Web  
**Grupo:** 4-C  
**Unidad:** I. Introducción al Desarrollo Web  

---

## 📌 Objetivo de la Actividad
Identificar las herramientas imprescindibles para el desarrollo web, verificar su instalación en el sistema operativo Windows y dejar el entorno completamente listo para trabajar.

---

## 🛠️ Herramientas Instaladas y Verificadas

| Herramienta | Versión Detectada | Rol Principal |
|---|---|---|
| **Node.js** | `v24.12.0` | Motor para ejecutar JavaScript del lado del servidor y herramientas de compilación |
| **NPM** | `11.6.2` | Gestor para instalar librerías, dependencias y frameworks (como Angular) |
| **Git** | `2.52.0.windows.1` | Control de versiones para guardar el historial del código |

---

## 🚀 Cómo Ejecutar el Script de Verificación
Para comprobar el estado de tu entorno en cualquier momento:

```bash
node verificar-entorno.js
```
