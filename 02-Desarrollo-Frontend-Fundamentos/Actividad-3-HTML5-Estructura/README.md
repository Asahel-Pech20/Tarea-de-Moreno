# Actividad 3: Estructura del Lenguaje de Marcado (HTML5)

**Materia:** Aplicaciones Web  
**Grupo:** 4-C  
**Unidad:** II. Desarrollo del Front End  

---

## 📌 Objetivo de la Actividad
Dominar la maquetación semántica moderna en HTML5, estructurando contenido web con encabezados, navegación, artículos, tablas de datos y formularios funcionales.

---

## 🏗️ Estructura del Archivo `index.html`
El documento implementa las mejores prácticas del estándar HTML5:
* **Cabecera Semántica:** `<header>` y `<nav>` con lista de enlaces de navegación.
* **Cuerpo Principal:** `<main>` delimitando el contenido exclusivo de la página.
* **Artículos de Noticias:** `<article>` con información de fechas, autores y párrafos formateados.
* **Tabla de Horarios:** `<table>` con encabezados (`<thead>`) y celdas organizadas (`<tbody>`).
* **Formulario Completo:** `<form>` con campos de texto, correo con validación, selector desplegable y botones de acción.
* **Pie de Página:** `<footer>` con menciones de autoría y derechos.

---

## 🌐 Cómo Probar la Página
Haz doble clic sobre el archivo `index.html` para abrirlo en cualquier navegador web (Chrome, Edge, Firefox).
