2. La evolución de HTML5 y la Semántica

Fecha de publicación: 20 de Septiembre de 2026 | Autor: Redacción Web

A diferencia de las versiones antiguas de HTML que usaban solo etiquetas <div> para todo, HTML5 introdujo etiquetas con significado propio (como <header>, <article>, y <footer>), lo cual facilita la accesibilidad para personas con discapacidad y mejora el posicionamiento en buscadores como Google.
