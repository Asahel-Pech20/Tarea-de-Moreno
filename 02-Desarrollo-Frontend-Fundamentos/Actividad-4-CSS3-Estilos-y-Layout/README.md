# Actividad 4: Hojas de Estilos en Cascada (CSS3)

**Materia:** Aplicaciones Web  
**Grupo:** 4-C  
**Unidad:** II. Desarrollo del Front End  

---

## 📌 Objetivo de la Actividad
Diseñar una interfaz web moderna, limpia y totalmente responsiva utilizando CSS3, comprendiendo el modelo de caja, Flexbox y las media queries para dispositivos móviles.

---

## 🎨 Aspectos Clave de la Implementación
* **Variables CSS (`:root`):** Paleta de colores centralizada y fácil de mantener (azules, blancos, sombras y acentos).
* **Modelo de Caja (`box-sizing: border-box`):** Asegura cálculos de dimensiones predecibles y sin desbordes.
* **Flexbox:** Distribución fluida del menú de navegación y de las tarjetas de noticias.
* **Diseño Responsivo (`@media`):** Adaptación fluida para pantallas menores a 768px (pantallas de teléfonos móviles).
* **Efectos y Microinteracciones:** Sombras suaves (`box-shadow`) y transiciones hover (`transition: all 0.3s ease`).

---

## 🌐 Cómo Probar la Práctica
Abre el archivo `index.html` en tu navegador. Puedes cambiar el tamaño de la ventana o usar la herramienta de inspección (F12 -> modo móvil) para comprobar cómo el diseño se adapta automáticamente.
