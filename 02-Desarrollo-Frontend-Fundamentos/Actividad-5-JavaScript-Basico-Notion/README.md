## 📌 Las 10 Prácticas Individuales de JavaScript

Cada práctica cuenta con su propio archivo independiente, comentado y listo para ejecutarse:

| # | Archivo | Tema Principal | Conceptos Clave |
|---|---|---|---|
| **01** | `practica-01-variables.js` | Variables y Tipos de Datos | `let`, `const`, tipos primitivos y `typeof` |
| **02** | `practica-02-funciones.js` | Funciones | Declarativas, de expresión y funciones flecha |
| **03** | `practica-03-scope-y-hoisting.js` | Scope y Hoisting | Alcance global vs. local/bloque y elevación |
| **04** | `practica-04-coercion-y-operadores.js` | Coerción y Operadores | Implícita/explícita, Truthy/Falsy e igualdad `===` |
| **05** | `practica-05-condicionales.js` | Estructuras Condicionales | `if`, `else if`, `else` y operador ternario |
| **06** | `practica-06-juego-piedra-papel-tijera-if.js` | Reto 1: Piedra, Papel o Tijera | Lógica del juego resuelta con `if/else` |
| **07** | `practica-07-juego-piedra-papel-tijera-switch.js` | Reto 2: Piedra, Papel o Tijera | Lógica del juego resuelta con `switch (true)` |
| **08** | `practica-08-arrays-y-metodos.js` | Arrays y Métodos de Mutación | Índices, `.push()`, `.pop()`, `.shift()`, `.unshift()` |
| **09** | `practica-09-bucles-for-y-while.js` | Bucles y Repetición | `for`, `for...of`, `while` y `do...while` |
| **10** | `practica-10-objetos-y-reto-constructores.js` | Objetos y Reto de Constructores | Objetos, constructores y **generación de 30 autos** |
| *Extra* | `practica-11-metodos-recorrido-arrays.js` | Métodos de Recorrido ES6+ | `.filter()`, `.map()`, `.find()`, `.some()`, `.forEach()` |

## 🚀 ¿Cómo Ejecutar las Prácticas?

Puedes ejecutar cualquiera de las prácticas de forma individual:
```bash
node practica-01-variables.js
node practica-06-juego-piedra-papel-tijera-if.js
node practica-10-objetos-y-reto-constructores.js
```

O ejecutar el probador maestro que corre todas en serie:
```bash
node ejecutar-todos-los-ejercicios.js
```
